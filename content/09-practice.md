# Practice exercise

Do this before your first real MM010. It takes about twenty minutes. Use the **Build and check** page, or download a fresh MM010 template from forms.uct.ac.za and fill it in for the scenario below, then compare with the model answer.

## The scenario

Your society's events officer is running an "Intro to Git" workshop on **Thursday 12 March 2027** at 13:00 in the Chris Hani lecture theatre, for 40 people. She wants lunch boxes. She has found a coffee shop in Mowbray called **Suraya's** and asked them for a quote, which arrived by email today, **26 February 2027**.

Here is the quote, made out to the University of Cape Town.

| | |
| --- | --- |
| Quote number | SR-2027-031 |
| Date | 26 February 2027 |
| Delivery | 12 March 2027, 12:30, Chris Hani Building |
| 40 x Lunch box (chicken or veg) at R57.50 | R2 300.00 |
| 1 x Delivery | R150.00 |
| Subtotal (excl. VAT) | R2 130.43 |
| VAT at 15% | R319.57 |
| **Total** | **R2 450.00** |

Use your own name and number as the requester.

## Your tasks

1. Is this vendor registered with UCT? Use the vendor search. Write down the vendor name as registered and the vendor number.
2. Fill in every field of the MM010. Use placeholder digits for the three society numbers if you do not have yours yet.
3. Write down which date you would submit it by, and why.
4. Write the one-line email you would send to the fund holder mailbox.

Do not open the model answer until you have done all four.

:::reveal Model answer
**1. The vendor.** Searching "Suraya" finds **Suraya's Restaurant Coffee Shop**, Mowbray, vendor number **204246**, in the Restaurants category. It is registered, so UCT can pay it.

**2. The form.**

| Field | Value |
| --- | --- |
| Requester name | your name |
| Tel. | your number |
| Department | Department of Student Affairs |
| Date | 26/02/2027 |
| Purchasing group | your society's name |
| Vendor name | Suraya's Restaurant Coffee Shop |
| Vendor number | 204246 |
| Item details | Q#SR-2027-031 lunch Git workshop 12/03 |
| Qty | 1 |
| Unit net amount (excl. VAT) | 2130.43 |
| Currency | ZAR |
| Total ZAR amount (excl. VAT) | 2130.43 |
| Fund number, cost centre, GL | your society's three numbers |
| TOTAL | 2130.43 |
| Vendor selection procedure followed | YES |
| Conflict of interest | NO |
| Fund holder, thresholds, processing | blank |

If you wrote **2450.00** anywhere on the form, that is the VAT-inclusive total and the form is wrong. The MM010 wants R2 130.43. If you split it into two rows (40 lunch boxes at R50.00 excluding VAT, and delivery at R130.43), that is also correct, as long as the two rows add up to 2130.43.

If you wrote "Suraya's" or "Surayas Coffee Shop" as the vendor name, that is the mistake to fix: use the registered name from the search.

**3. When to submit.** Today, 26 February, or at the latest the next day. The event is on 12 March, fourteen days away, which is the minimum lead time on this site. Any correction from the fund holder would push the PO past the event.

**4. The email.** Something like: "Hi, please find attached the MM010 (Word) and quote for lunch for our Git workshop on 12 March, R2 130.43 excluding VAT, vendor Suraya's Restaurant Coffee Shop (204246). Could you sign and forward to Student Treasury? Thank you." Attach both files, the quote named `YourSociety_26_Feb_2027.pdf`. Do not paste the society numbers into the email body.
:::

## A second scenario, no model answer

Your media officer wants 200 A5 flyers printed for an event. She has a quote from a printer in Howard Place for R1 380.00 including VAT and delivery, quote number TPP/1198, dated 3 October, for delivery on 17 October. Find the printer, fill in the form, and ask the previous treasurer to check it. That is a better test than a model answer.
